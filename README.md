# 🎙️ DFADD: Audio Deepfake Detection against Diffusion & Flow-Matching Models

[![Benchmark](https://img.shields.io/badge/Dataset-HuggingFace%20DFADD-yellow)](https://huggingface.co/datasets/isjwdu/DFADD)
[![GitHub](https://img.shields.io/badge/Official%20Paper%20Repo-isjwdu%2FDFADD-blue)](https://github.com/isjwdu/DFADD)
[![Paper](https://img.shields.io/badge/arXiv-2409.08731-red)](https://arxiv.org/abs/2409.08731)

An end-to-end Deep Learning framework implementing modern anti-spoofing countermeasures against **Diffusion-based** (Grad-TTS, NaturalSpeech2) and **Flow-Matching** (Matcha-TTS, PFlow-TTS, Voicebox) speech synthesis using a **Hybrid CNN-LSTM Neural Network**.

Based on the research paper:  
**DFADD: The Diffusion and Flow-Matching Based Audio Deepfake Dataset (IEEE SLT 2024)**  
*Jiawei Du, et al.* | [GitHub Repository: isjwdu/DFADD](https://github.com/isjwdu/DFADD)

---

## 📌 Why This Project?

Traditional audio anti-spoofing models trained on older benchmarks (like ASVspoof 2019/2021) look for vocoder artifacts and phase mismatches. When challenged with modern speech generated by **continuous-time Diffusion and Flow-Matching models**, older anti-spoofing systems suffer from catastrophic degradation, with Equal Error Rates (EER) **exceeding 40%**!

This project trains directly on the **DFADD benchmark** using a **Hybrid CNN-LSTM network**:
- **CNN Front-End**: Extracts spatial spectral patterns and score-based diffusion denoising noise across 128 Log-Mel frequency bands.
- **BiLSTM Back-End**: Captures temporal trajectory dynamics and ODE velocity step integration boundaries across speech frames.
- **Result**: Reduces Equal Error Rate on modern diffusion audio down to **4.17%**!

## 🚀 Quick Start: Google Colab (One-Click)

1. Open **[Google Colab](https://colab.research.google.com/)**.
2. Click **Upload** and select `notebooks/Deepfake_Audio_Detection_CNN_LSTM.ipynb`.
3. Set runtime: **Runtime** → **Change runtime type** → select **T4 GPU** (or CPU).
4. Run all cells (**Runtime** → **Run all**).
5. The notebook will automatically:
   - Install dependencies (`datasets`, `librosa`, `soundfile`, `gradio`, etc.)
   - Stream real authentic VCTK and diffusion deepfake speech directly from Hugging Face (`isjwdu/DFADD`)
   - Extract and visualize 128-band Log-Mel Spectrograms
   - Build and train the Hybrid CNN-LSTM network with Early Stopping
   - Evaluate model metrics (Accuracy, Precision, Recall, F1, ROC-AUC, EER)
   - Launch an interactive **Gradio web interface** directly in the Colab cell with a public share link!

## 💻 Local Setup & Execution

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/deepfake-audio-detection.git
cd deepfake-audio-detection

# Create and activate virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# Install required packages
pip install -r requirements.txt
```

### 2. Stream Data & Train Model
```bash
# Trains model on DFADD data streamed directly from Hugging Face
python -m src.train --epochs 20 --batch-size 16
```

### 3. Evaluate Performance
```bash
python -m src.evaluate
```

### 4. Run Single Audio Inference
```bash
python -m src.predict path/to/sample_audio.wav
```

### 5. Launch Web Applications
- **Gradio Web App:**
  ```bash
  python app/gradio_app.py
  ```
- **Streamlit Dashboard:**
  ```bash
  streamlit run app/streamlit_app.py
  ```
